# 网页即组件布局-vibe coding常用"黑话"⑤——3种弹窗 & 6种表单控件

# 一、3种弹窗类型详解

## 开篇

你是不是也这样？一句"做个弹窗"，AI就开始猜题。

一个小小的弹窗，做成了大大的卡片。然后自己想要修改但是奈何词不达意，只能描述，不能用专业名词直击要害。

同样是浮在页面上，居中弹窗、侧边抽屉、气泡弹窗，用法完全不同。

## 3种弹窗类型详解

### 1. 居中弹窗（Modal）

- 特点：必须先处理，再继续操作，会打断当前任务
- 适用场景：删除确认、支付确认等需要用户明确决策的操作

<video controls src="/videos/pop-modal.mp4" style="width:100%"></video>
### 2. 侧边抽屉（Drawer）

- 特点：内容多，又想保留原页面上下文
- 适用场景：各种表单填写、内容编辑等需要大量操作的场景

<video controls src="/videos/pop-drawer.mp4" style="width:100%"></video>
### 3. 气泡弹窗（Popover）

- 特点：少量内容，紧贴触发点，操作轻，不打断整个页面
- 适用场景：按钮附近的少量选项，比如账号操作、文件操作等

<video controls src="/videos/pop-popover.mp4" style="width:100%"></video>
## 弹窗小结

下次做弹窗，记得先判断三个问题：

- 打不打断当前操作？
- 内容多不多？
- 离触发点近不近？

别再只说"做个弹窗"，要告诉AI这四件事：

1. 类型
2. 触发位置
3. 关闭方式
4. 里面放什么

# 二、6种表单控件详解

## 开篇

别再跟AI说"做个输入框"，它真的不知道你要哪一种。

先判断是输入，还是选择，再说出准确的控件名。

## 6种表单控件详解

### 1. 单行文本框 | Text Field

- 适用场景：填姓名、邮箱、公司名等短内容，只填一行
- 指令示例：创建"姓名"字段，显示占位文字并设为必填

<video controls src="/videos/form-textfield.mp4" style="width:100%"></video>
### 2. 多行文本框 | Textarea

- 适用场景：写简介、需求、反馈等需要写一段话的内容
- 指令示例：创建"需求描述"字段，在下方显示字数统计

<video controls src="/videos/form-textarea.mp4" style="width:100%"></video>
### 3. 下拉选择 | Select

- 适用场景：从一组固定答案里选一个，比如所在城市
- 指令示例：创建"所在城市"下拉选择框，默认显示"请选择"

<video controls src="/videos/form-select.mp4" style="width:100%"></video>
### 4. 可搜索选择框 | Combobox

- 适用场景：选项太多时，先输入关键词搜索，再从结果中选择
- 指令示例：创建"邀请成员"字段，输入姓名时实时筛选结果

<video controls src="/videos/form-combobox.mp4" style="width:100%"></video>
### 5. 单选按钮组 | Radio Group

- 适用场景：选项少，需要直接比，并且只能选一个，比如配送方式
- 指令示例：横向展示3种配送方式，默认选中"普通配送"

<video controls src="/videos/form-radio.mp4" style="width:100%"></video>
### 6. 复选框 | Checkbox

- 适用场景：兴趣、偏好、同意条款等，可以同时选择多个
- 指令示例：展示兴趣标签，允许多选，最多选择3项

<video controls src="/videos/form-checkbox.mp4" style="width:100%"></video>
## 表单总结

短内容用 Text Field，长内容用 Textarea

固定选择用 Select，边搜边选用 Combobox

单选用 Radio Group，多选用 Checkbox
