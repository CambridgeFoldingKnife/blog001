# 网页即组件布局-vibe coding常用"黑话"③——6种Tab控件

## 开篇

一个视频教会你6种好看的Tab怎么和AI说。

## 6种Tab控件详解

### 1. 线性滑块标签 | LINEAR SLIDER

- 特点：细线跟随滑动，选中项有下划线跟随，切换时内容同步变化
- 适合场景：后台看板、详情页等同级栏目，用户频繁切换时也能快速确认当前位置
- 指令示例：做线性滑块标签，当前选中项下有一条细线跟随滑动，切换时内容同步更新。

<video controls src="/videos/tab-linearslider.mp4" style="width:100%"></video>
### 2. 卡片式标签页 | CARD TABS

- 特点：标签与面板相连，未选中项保留浅色卡片轮廓，选中项变成白色并去掉底边，与下方内容无缝连接成一体
- 适合场景：成员管理、订单设置等信息密集的后台模块，用明显分区降低视觉压力
- 指令示例：做卡片式标签页，选中的标签变白并与下方内容连成一体，未选中保留浅灰卡片轮廓。

<video controls src="/videos/tab-cardtabs.mp4" style="width:100%"></video>
### 3. 鱼骨式步骤标签 | CHEVRON STEPPER

- 特点：步骤首尾相接，各步骤间用直角箭头连接，区分已完成、当前和未开始状态，点击步骤时高亮并切换对应内容
- 适合场景：结账、开户、发布流程等有明确先后顺序的任务，让当前进度和下一步一目了然
- 指令示例：做鱼骨式步骤标签，步骤用直角箭头首尾相连，区分已完成/当前/未开始状态，点击步骤切换内容。

<video controls src="/videos/tab-chevron.mp4" style="width:100%"></video>
### 4. 分段控件标签 | SEGMENTED CONTROL

- 特点：同一轨道内切换，把少量互斥选项放进一条圆角轨道，选中项平滑移动到点击点，并立即更新下方数据/图表
- 适合场景：同一数据范围内切换两到四种视图，例如今日/本月/全年列表或图表
- 指令示例：做分段控件，把今日/本月/全年放进一条圆角轨道，选中项平滑移动并同步更新下方图表。

<video controls src="/videos/tab-segmented.mp4" style="width:100%"></video>
### 5. 文件夹标签 | FOLDER TABS

- 特点：页签连接内容面板，页签左边是90°折角，右边是38°斜边，选中项叠在最上层，并与下方内容形成连续的视觉整体
- 适合场景：项目资料、文档库和档案分类，让不同内容组像翻阅实体文件夹一样直观
- 指令示例：做文件夹标签，页签带一个折角，选中项叠在最上层并与下方内容面板连成整体。

<video controls src="/videos/tab-folder.mp4" style="width:100%"></video>
### 6. 图片预览标签 | IMAGE PREVIEW TABS

- 特点：缩略图切换主图，每个标签同时展示图片背景并叠加标题，点击后突出当前缩略图，同时把上方Banner切换为同一张大图
- 适合场景：作品集、空间案例、旅行和商品展示，让用户先看缩略图再选择浏览内容
- 指令示例：做图片预览标签，点击缩略图切换上方大图，并高亮当前选中的缩略图。
