# 网页即组件布局-vibe coding常用"黑话"④——5种侧边栏 & 5种登录页

# 一、5种侧边栏详解

## 开篇

同样是侧边栏，为什么别人做得像设计作品，你的却像十年前的管理后台？

今天一次教会你5种有设计感的侧边栏。

## 5种侧边栏详解

### 1. 悬浮岛式侧边栏

- 特点：不贴页面边缘，四周留白，像一张独立悬浮的圆角卡
- 适合场景：需要精致感的产品后台、工具类应用
- 指令示例：做悬浮岛式侧边栏，不贴页面边缘、四周留白，做成一张独立悬浮的圆角卡片。

<video controls src="/videos/sidebar-island.mp4" style="width:100%"></video>
### 2. 弧形滚轮式侧边导航

- 特点：选项沿圆弧滚动，到达基准线右侧才高亮，远端选项会旋转、淡出和模糊
- 适合场景：品牌官网、创意类网站，打造动态视觉效果
- 指令示例：做弧形滚轮式侧边导航，选项沿圆弧滚动，滚动到基准线才高亮，远端选项旋转淡出模糊。

<video controls src="/videos/sidebar-wheel.mp4" style="width:100%"></video>
### 3. 多级侧边栏

- 特点：父级菜单负责归类，点击后展开缩进的子菜单，适合功能复杂的后台
- 适合场景：电商后台、企业管理系统、内容管理平台
- 指令示例：做多级侧边栏，点击父级菜单展开缩进的子菜单，适合功能复杂的后台。

<video controls src="/videos/sidebar-multi.mp4" style="width:100%"></video>
### 4. 可折叠侧边栏

- 特点：展开时显示图标与文字，收起后只保留图标，把空间还给主内容
- 适合场景：数据看板、监控系统，平衡导航需求与内容展示空间
- 指令示例：做可折叠侧边栏，展开时显示图标和文字，收起后只留图标，把空间还给内容。

<video controls src="/videos/sidebar-collapse.mp4" style="width:100%"></video>
### 5. 隐藏式侧边栏

- 特点：默认藏在画布外，点击菜单按钮滑入，同时三横线变成关闭符号，再点一次关闭
- 适合场景：内容密集的博客、文档站，最大化内容展示区域
- 指令示例：做隐藏式侧边栏，默认藏在画面外，点击菜单按钮滑入，再点一次关闭，菜单图标切换成关闭符号。

<video controls src="/videos/sidebar-hidden.mp4" style="width:100%"></video>
## 侧边栏小结

记住这五种类型，告诉AI，你也能做出有设计感的侧边栏。

# 二、5种登录页详解

## 开篇

只跟AI说"做个高级的登录页"，难怪每次都像同一个模板。

别只说"高级"，先说布局类型，再补背景、卡片和品牌气质。

## 5种登录页样式详解

### 1. 居中卡片式登录页

- 特点：稳妥、通用，适合大多数工具和SaaS产品
- 指令示例：做居中卡片式登录页，卡片悬浮，页面留白充足

<video controls src="/videos/login-centered.mp4" style="width:100%"></video>
### 2. 左右分屏式登录页

- 特点：同时完成品牌表达和用户登录，桌面端效果尤其清晰
- 指令示例：做左右分屏登录页，左边讲品牌，右边放表单

<video controls src="/videos/login-split.mp4" style="width:100%"></video>
### 3. 沉浸式背景式登录页

- 特点：让表单直接融入有色背景，用排版和底纹建立层次，不再靠卡片
- 指令示例：使用全屏沉浸式背景，登录框覆盖其上，并加深色遮罩保证可读性

<video controls src="/videos/login-immersive.mp4" style="width:100%"></video>
### 4. 多角色Tab登录页

- 特点：在同一表单里切换身份，让用户直接看见个人端与企业端的字段差异
- 指令示例：用Tab切换个人用户和企业管理员，并展示两种身份不同的登录字段

<video controls src="/videos/login-roles.mp4" style="width:100%"></video>
### 5. 分步登录式

- 特点：验证步骤较多时，一屏只做一件事，降低用户的理解和操作负担
- 指令示例：把登录拆分成步流程，一屏只完成一个任务，并展示进度与返回入口

<video controls src="/videos/login-step.mp4" style="width:100%"></video>
