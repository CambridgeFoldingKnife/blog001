# 网页即组件布局-vibe coding常用"黑话"②——8种特殊控件

## 开篇

这种叫做走马灯，那这种、这种、还有这种呢？

一个视频教会你8种特殊控件，分别叫什么。

## 8种特殊控件详解

### 1. 走马灯 | Carousel

- 作用：自动轮播，一张张切换
- 适合场景：首页横幅、活动宣传等轮播展示
- 指令示例：做走马灯，图片自动轮播也能手动左右切换，配小圆点或箭头指示。

<video controls src="/videos/ctrl-carousel.mp4" style="width:100%"></video>
### 2. 数字输入框 | Number Input

- 作用：点加减或直接输入，精确改数值
- 适合场景：数量、尺寸等需要精确设定的数值
- 指令示例：做数字输入框，支持点加减按钮和直接输入数值，设置最小值和最大值。

<video controls src="/videos/ctrl-numberinput.mp4" style="width:100%"></video>
### 3. 时间轴 | Timeline

- 作用：一条线串起节点，按时间展示进展
- 适合场景：发展历程、项目进度等时间线展示
- 指令示例：做时间轴，用一条竖线串起节点，每个节点标上时间和内容，用图标区分状态。

<video controls src="/videos/ctrl-timeline.mp4" style="width:100%"></video>
### 4. 翻页器 | Pagination

- 作用：点页码或箭头，切换列表页
- 适合场景：列表、搜索结果等长内容分页
- 指令示例：做翻页器，在列表下方放页码和上一页/下一页箭头，高亮当前页。

<video controls src="/videos/ctrl-pagination.mp4" style="width:100%"></video>
### 5. 徽标 | Badge

- 作用：标出数量或状态
- 适合场景：消息未读、新品、热门等数量与状态标记
- 指令示例：做徽标，在图标右上角显示数字角标提示未读数量，或用小标签标注新品、热门状态。

<video controls src="/videos/ctrl-badge.mp4" style="width:100%"></video>
### 6. 边框流光 | Glow Border

- 作用：高光沿边框流动，突出卡片
- 适合场景：会员卡、重点功能卡等需要吸睛的卡片
- 指令示例：做边框流光卡片，一条光带沿着卡片边缘循环流动，突出最想让人注意的那张卡。

<video controls src="/videos/ctrl-glowborder.mp4" style="width:100%"></video>
### 7. 骨架屏 | Skeleton

- 作用：加载时先用占位块过渡
- 适合场景：页面、列表加载时的占位过渡
- 指令示例：做骨架屏，页面加载时先用灰色占位块勾勒结构，加载完再替换成真实内容。

<video controls src="/videos/ctrl-skeleton.mp4" style="width:100%"></video>
### 8. 开关 | Toggle Switch

- 作用：立即切换两种状态
- 适合场景：深色模式、消息提醒等开关型设置
- 指令示例：做开关，点击后立即在开启/关闭两种状态间切换，用颜色区分两种状态。

<video controls src="/videos/ctrl-toggle.mp4" style="width:100%"></video>
