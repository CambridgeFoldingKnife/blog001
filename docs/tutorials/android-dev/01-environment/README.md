# 🛠️ 开发环境与工程结构

> 先把环境搭好，再谈写代码

## 📚 本章概述

这一章解决「跑起来」的问题：装好 Android Studio、看懂新建工程后每个文件是干什么的、改掉默认的 App 名称和图标。

## 📖 计划内容

本章笔记正在整理，将包含以下内容：

1. Android Studio 环境搭建（SDK、模拟器、真机调试）
2. 安卓项目的启动顺序（从点击图标到界面显示经历了什么）
3. 修改 App 名称和图标
4. libs.versions.toml 依赖版本管理详解

> **特别注意**
> 在环境搭好之前，你可以先去 [Kotlin 基础语法](../02-kotlin-basics/) 学语法，这部分不依赖 Android 环境。
