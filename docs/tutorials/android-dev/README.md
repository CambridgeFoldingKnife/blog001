# 🤖 Android 开发教程

> 从 Kotlin 语法到 Android 应用开发，一条完整的 Android 学习路线

## 📚 教程简介

Android 是目前市场占有率最高的移动操作系统，Kotlin 是 Google 官方推荐的 Android 开发语言。本教程按「环境搭建 → 语言基础 → 框架开发 → 项目实战」的顺序组织，把我学习 Android 过程中的笔记、踩坑记录和代码片段整理成可以照着敲的实操教程。

### 🎯 你会学到什么

- ✅ 用 Android Studio 搭好开发环境，看懂工程目录
- ✅ 掌握 Kotlin 基础语法、面向对象、集合与 Lambda
- ✅ 熟悉 Activity、布局、状态栏、数据持久化等基础开发能力
- ✅ 用一个小项目把知识点串起来

## 📖 学习路线

### [第一章：开发环境与工程结构](01-environment/) 
- Android Studio 环境搭建
- 安卓项目的启动顺序
- 修改 App 名称和图标
- libs.versions.toml 依赖版本管理

### [第二章：Kotlin 基础语法](02-kotlin-basics/) ⭐⭐⭐⭐⭐
- Kotlin 初识与运行原理
- 认识 MainActivity 与项目结构
- 变量、基本数据类型与类型推断

- 集合操作

### [第三章：Android 基础开发](03-android-basics/) 
- SharedPreferences 持久化

### [第四章：小项目实战](04-practice/)

## 💡 学习建议

1. **先跑通再理解**：环境搭好后，先把每段代码跑一遍看效果，再回头理解语法。
2. **Kotlin 不需要真机**：Kotlin 代码跑在 JVM 上就行，语法阶段不用急着连手机。
3. **笔记跟着代码走**：每学一个知识点，写一个能运行的小例子，比抄定义有用得多。

> **特别注意**
> 本教程的 Android 部分基于当前主流的 Kotlin + Jetpack 方案，如果你看到的是 Java 写法，属于旧教程，注意区分。
