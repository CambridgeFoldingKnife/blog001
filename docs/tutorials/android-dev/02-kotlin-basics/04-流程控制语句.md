# 流程控制语句

写程序说到底就三件事：顺序、分支、循环。这一篇我们把分支（`if`、`when`）和循环（`for`）一次说透。Kotlin 最大的不同是——它们都是**表达式**，能直接返回值。

## 一、if 语句

### 1.1 最普通的条件分支

写法和 Java 几乎一样，只是不用写分号：

```kotlin
fun main() {
    val score = 85

    if (score >= 90) {
        println("优秀")
    } else if (score >= 60) {
        println("及格")
    } else {
        println("不及格")
    }
}
```

<img src="/images/android-dev/02-kotlin基础语法_03-流程控制语句-1.png" alt="Kotlin if 条件分支示例" style="zoom:50%;" />

判断顺序要从严格到宽松。如果先判断 `>= 60`，那 95 分也会被归到"及格"，后面的"优秀"永远进不去。

### 1.2 if 作为表达式返回值

Kotlin 的 `if` 不只是语句，还能直接当值用：

```kotlin
fun main() {
    val score = 72
    val level = if (score >= 60) "及格" else "不及格"
    println(level)   // 及格
}
```

> **特别注意**
> `if` 作为表达式使用时，`else` 分支必须写。编译器要保证"任何情况下都有值返回"，少了 `else` 会直接编译报错。

## 二、when 流程控制

`when` 是 Kotlin 对 Java `switch` 的全面升级，有三种最常见的写法。

### 2.1 带参数的 when

最像 `switch` 的用法，但不用写 `break`，分支也不会"穿透"：

```kotlin
fun describeDay(day: Int): String {
    return when (day) {
        1, 2, 3, 4, 5 -> "工作日"
        6, 7 -> "周末"
        else -> "输入有误"
    }
}
```

一个分支可以匹配多个值，用逗号隔开就行。

<img src="/images/android-dev/02-kotlin基础语法_03-流程控制语句-2.png" alt="Kotlin when 表达式用法" style="zoom:50%;" />

### 2.2 无参数的 when

不写括号里的参数，每个分支写自己的布尔条件，相当于一串 `if-else if`：

```kotlin
fun checkScore(score: Int): String {
    return when {
        score >= 90 -> "优秀"
        score >= 60 -> "及格"
        score in 0..59 -> "不及格"
        else -> "分数不合法"
    }
}
```

### 2.3 用区间做分支

`when` 的分支支持 `in` 区间判断，写分数段、年龄段非常舒服：

```kotlin
fun grade(score: Int) = when (score) {
    in 90..100 -> "A"
    in 80 until 90 -> "B"
    in 60 until 80 -> "C"
    in 0 until 60 -> "D"
    else -> "分数不合法"
}
```

> **常见错误**
> 如果写成 `in 90..100` 和 `in 80..90`，90 分会被第一个分支截走。写区间分支时一定要检查边界有没有打架。

## 三、for 语句

### 3.1 range、until、downTo、step

```kotlin
fun main() {
    for (i in 1..5) print("$i ")                // 1 2 3 4 5，闭区间
    println()
    for (i in 1 until 5) print("$i ")           // 1 2 3 4，左闭右开
    println()
    for (i in 10 downTo 1) print("$i ")         // 10 9 ... 1，倒序
    println()
    for (i in 10 downTo 1 step 2) print("$i ")  // 10 8 6 4 2，步长
    println()
}
```

<img src="/images/android-dev/02-kotlin基础语法_03-流程控制语句-3.png" alt="Kotlin for 循环与区间" style="zoom:50%;" />

### 3.2 遍历集合

```kotlin
fun main() {
    val fruits = listOf("苹果", "香蕉", "橙子")

    for (fruit in fruits) println(fruit)
    for ((index, fruit) in fruits.withIndex()) println("$index -> $fruit")

    val user = mapOf("name" to "剑桥折刀", "age" to "18")
    for ((key, value) in user) println("$key = $value")
}
```

> **特别注意**
> `for (i in 0..names.size)` 会多循环一次，最后一次访问 `names[names.size]` 直接越界崩溃。数组下标遍历请用 `until` 或 `indices`。

## 四、小结

`if` 和 `when` 都能当表达式返回值，代码可以写得很"扁平"，少了很多临时变量。`when` 的三种形态分别对应"值匹配、条件匹配、区间匹配"。`for` 记住四个关键词：`..` 闭区间、`until` 左闭右开、`downTo` 倒序、`step` 步长。
