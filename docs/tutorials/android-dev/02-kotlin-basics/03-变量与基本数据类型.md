# 变量与基本数据类型

上一篇我们知道 Kotlin 代码跑在 JVM 上，这一篇就用最朴素的方式练习：写 `main` 函数，用 `println` 看结果。别小看这些基础，Android 项目里天天都在用。

## 一、打印和输出

`println` 会自动换行，`print` 不会，标准库里直接可用，不用 import：

```kotlin
fun main() {
    println("这一行会换行")
    print("这一行不会换行")
    print("，所以接在后面")
    println()
    println(1 + 2)
}
```

## 二、常量和变量：val 与 var

Kotlin 声明变量只有两个关键字：`val` 是只读变量（value），赋值后不能再改；`var` 是可变变量（variable），可以重新赋值。

```kotlin
fun main() {
    val pi = 3.14159
    var count = 0

    count = 10
    // pi = 3.14  // 编译报错：Val cannot be reassigned

    println("pi = $pi, count = $count")
}
```

### 2.1 为什么优先用 val

笔记里写得很清楚：**val 优先常用，开销小**。它只生成 getter、不生成 setter，运行时少一层可写检查；而且不可变的变量天然线程安全，读代码时不用担心中途被改。

> **特别注意**
> `val` 只是"引用不可变"，不是"内容不可变"。`val` 修饰的 `MutableList` 依然可以 `add`，只是不能把变量指向另一个列表。

## 三、基本数据类型

Kotlin 和 Java 有一个重要区别：**一切皆对象**，没有 `int` 和 `Integer` 之分。

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `Int` | 32 位整数 | `18` |
| `Long` | 64 位整数 | `8_100_000_000L` |
| `Double` | 64 位小数 | `9.9` |
| `Float` | 32 位小数 | `0.75f` |
| `Boolean` | 布尔值 | `true` |
| `Char` | 单个字符 | `'A'` |
| `String` | 字符串 | `"剑桥折刀"` |

```kotlin
fun main() {
    val age: Int = 18
    val population: Long = 8_100_000_000L
    val price: Double = 9.9
    val rate: Float = 0.75f
    val isVip: Boolean = true
    val grade: Char = 'A'
    val name: String = "剑桥折刀"

    println("$age / $population / $price / $rate / $isVip / $grade / $name")
}
```

`Long` 字面量要加 `L`，`Float` 要加 `f`，不加会被当成 `Int` 和 `Double`；数字里可以用 `_` 分隔，读起来更清楚。

## 四、类型推断和类型转换

### 4.1 类型推断

声明时直接给初始值，Kotlin 会自动推断类型：`val number = 100` 是 `Int`，`100L` 是 `Long`，`"3.14"` 是 `String`；先声明后赋值就必须显式写类型，例如 `val score: Int` 再 `score = 95`。

### 4.2 类型转换必须显式

这是和 Java 差异最大的地方之一：**没有隐式类型转换**，必须调用转换函数。

```kotlin
fun main() {
    val text = "3.14"
    val pi: Double = text.toDouble()  // String -> Double
    val count: Int = pi.toInt()       // Double -> Int，直接截断
    val big: Long = count.toLong()    // Int -> Long

    println("pi = $pi, count = $count, big = $big")
    // val wrong: Long = count  // 编译报错，必须写 count.toLong()
}
```

常用转换有 `toInt()`、`toLong()`、`toDouble()`、`toString()`。`toInt()` 是**截断**不是四舍五入，`3.99.toInt()` 的结果是 `3`。

> **常见错误**
> 从输入框或 JSON 里拿到的数字其实是 `String`。先转一下还能顺手处理空值：`val age = input.toIntOrNull() ?: 0`

## 五、函数调用

```kotlin
fun main() {
    val numbers = listOf(3, 1, 2)

    println(numbers.sorted())      // [1, 2, 3]
    println(numbers.maxOrNull())   // 3
    println("kotlin".uppercase())  // KOTLIN
    println(maxOf(3, 5))           // 5
    println("  hi  ".trim())       // hi
}
```

调用规则和 Java 差不多：`对象.方法()`。区别是 `listOf` 这类顶层函数不需要写工具类名。

## 六、模板字符串

拼字符串别再写 `"年龄：" + age` 了：`$变量名` 直接插变量，`${表达式}` 里可以写任何表达式。

```kotlin
fun main() {
    val name = "剑桥折刀"
    val age = 18

    println("你好，我是 $name，今年 $age 岁")
    println("明年我就 ${age + 1} 岁了")
    println("1 + 2 = ${1 + 2}")
    println("名字长度是 ${name.length}")
    println("价格是 \$9.9")   // 输出美元符号要转义
}
```

`$` 后紧跟标识符时会把整个标识符当成变量名，`$nameSuffix` 会被当成变量 `nameSuffix`，这时用 `${name}Suffix` 划清边界。

## 七、小结

`val` 优先、`var` 备用；基本类型首字母大写且全是对象；类型转换必须显式调用 `toXxx()`；字符串拼接首选 `${}` 模板。把这些练熟，下一章的流程控制才好上手。
